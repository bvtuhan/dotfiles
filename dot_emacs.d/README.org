* Windows Installation

** Post-Installation

Create a custom env. variable:
#+BEGIN_EXAMPLE
Variable name: HOME
Variable value: C:\Users\batuhan
#+END_EXAMPLE



** Package Dependencies

1. Download [[https://www.msys2.org/]]
2. We will be using =ucrt64.exe= for our =emacs= as well as the
   extensions.
#+BEGIN_SRC bash
pacman -Syu
pacman -S --needed \
mingw-w64-ucrt-x86_64-emacs \
mingw-w64-ucrt-x86_64-git \
mingw-w64-ucrt-x86_64-gcc \
mingw-w64-ucrt-x86_64-pkgconf \
mingw-w64-ucrt-x86_64-enchant \
mingw-w64-ucrt-x86_64-hunspell \
mingw-w64-ucrt-x86_64-hunspell-en

echo 'export PATH="/mingw64/bin:$PATH"' >> ~/.bashrc
echo 'export PATH="/ucrt64/bin:$PATH"' >> ~/.bashrc

hunspell -d en_US -D
mkdir -p ~/.local/share/dict
tail -n +2 /ucrt64/share/hunspell/en_US.dic \
  | sed 's#/.*##' \
  | tr -d '\r' \
  > ~/.local/share/dict/en_US.words
#+END_SRC
